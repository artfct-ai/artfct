# Behavior map

This file lists each effect a person sees or the system relies on, and the invariants that guard it. A scheduled audit compares the code against it.

Effects use the terms of the glossary. A guard is the exact function name of an invariant. A guard written `module::name` is an invariant of that Quint spec module. A guard written `world::name` is a check the workflow world in `packages/orchestrator/test/workflow-world.ts` makes on every step, so every property test and replay that drives the world makes it. A guard written `tests::path` names the example tests in that test file. A row with an empty guard list is unguarded.

The router binding invariants live in the Quint spec at `spec/router-bindings/routerBindings.qnt`. The review loop invariants live in the Quint spec at `spec/review-loop/reviewLoop.qnt`, the workflow lifecycle invariants in `spec/workflow-lifecycle/workflowLifecycle.qnt`, the harness session invariants in `spec/harness-session/harnessSession.qnt`, the agent turns invariants in `spec/agent-turns/agentTurns.qnt`, the chat acknowledgement invariants in `spec/chat-acknowledgement/chatAcknowledgement.qnt`, the session routing invariants in `spec/session-routing/sessionRouting.qnt`, and the feedback routing invariants in `spec/feedback-routing/feedbackRouting.qnt`. A guard written `webhookInvariants::name` is a webhook invariant in `packages/ingress/test/webhook-invariants.ts`, and one written `inboundInvariants::name` is an inbound mapper invariant in `packages/adapters/test/inbound-invariants.ts`. A guard written `slackTextInvariants::name` is a Slack text invariant in `packages/adapters/test/slack-text-invariants.ts`. A guard written `githubCodeInvariants::name` is a GitHub code invariant in `packages/adapters/test/github-code-invariants.ts`. A guard written `documentsInvariants::name` is a document host invariant in `packages/adapters/test/documents-invariants.ts`.
