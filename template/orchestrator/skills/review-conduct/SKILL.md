name: review-conduct
description: Ground every finding and keep a repeat review to what changed. Use this with any skill that reviews an artifact and files findings.
---

## Objective
File only findings that change the outcome, each one grounded in the artifact.

## Finding Rules
- **Read** the context around a part before you judge it.
- **Give** every finding a location and the input or state that produces the wrong result.
- **Drop** a finding you cannot ground.
- **Report** only what changes the outcome. Note nitpicks clearly.
- **Accept** an empty result. No findings is a valid review.

## Repeat Review
Apply these when an earlier review left findings and the author changed the artifact or replied since.
- **Check** what the author did with each earlier finding.
- **Review** what changed.
- **Judge** a finding the author argued down on the reply.
- **Raise** a new finding only when it is functional and the earlier review missed it.

## Out of Scope
- **Do not restate** the artifact.
- **Do not invent** findings.
- **Do not reopen** what an earlier review accepted.
